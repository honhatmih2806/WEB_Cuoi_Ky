## 1. Bối Cảnh & Tầm Nhìn Dự Án (Vision & Concept)

### 1.1. Tại sao lại kết hợp Apple iPhone và NVIDIA?
Trên thị trường công nghệ hiện đại, hai thế lực dẫn đầu về trải nghiệm người dùng và sức mạnh tính toán chuyên sâu chính là **Apple** và **NVIDIA**:
* **Apple iPhone:** Dẫn đầu thế giới về thiết bị di động cá nhân, quay phim điện ảnh (ProRes 4K, Apple Log, Spatial Video 3D), màn hình Super Retina XDR ProMotion, vi xử lý A18 Pro với Neural Engine tiên tiến.
* **NVIDIA:** "Ông vua" thống trị kiến trúc AI thế giới, siêu chip đồ họa GeForce RTX (kiến trúc Blackwell RTX 50-Series, Ada Lovelace RTX 40-Series), hệ thống xử lý mô hình ngôn ngữ lớn (LLM), deep learning và nền tảng nhúng Edge AI (NVIDIA Jetson AGX Orin).
* **Điểm đột phá độc quyền — "Synergy Workflows":**
  1. **Nhà sáng tạo nội dung & Đạo diễn số (Digital Creators):** Quay video chất lượng 4K ProRes 120fps trên iPhone 16 Pro Max, truyền tải siêu tốc qua Thunderbolt/USB 3 sang Workstation trang bị NVIDIA RTX 4090/5090 để render DaVinci Resolve, Adobe Premiere và xử lý hiệu ứng Generative AI qua Tensor Cores.
  2. **Kỹ sư AI & Thị giác máy tính (AI / CV Researchers):** Thu thập dữ liệu hình ảnh/video trực tiếp từ cụm camera LiDAR của iPhone, huấn luyện mô hình thị giác trên GPU NVIDIA RTX và triển khai mô hình nén chạy on-device trên NVIDIA Jetson Orin Nano / iPhone Neural Engine.
  3. **Gamer & Streamer chuyên nghiệp:** Sử dụng sức mạnh tối thượng của NVIDIA RTX 4080/4090/5090 cho đồ họa Full Ray Tracing / Path Tracing kết hợp iPhone làm Studio Webcam 4K siêu nét qua Continuity Camera.

## 4. Các Tính Năng Nền Tảng (Core Feature Set)

### 4.1. Giao Diện & Trải Nghiệm Khách Hàng (Frontend Experience)
* **Giao diện "Titan Titanium & Cyber-Green":** Phối màu Dark Titanium sang trọng của Apple kết hợp ánh xanh phát quang đặc trưng của NVIDIA (`#76B900`). Giao diện sạch (clean), tối giản (minimalist), chuẩn công thái học.
* **Bộ lọc thông minh đa chiều:** Lọc theo Hãng (Tất cả, Apple, NVIDIA, Bundle), theo Danh mục, khoảng giá, tình trạng kho hàng, và thông số kỹ thuật (VRAM, Chipset).
* **Công cụ tư vấn giải pháp thông minh (AI Synergy Advisor):** Người dùng nhập nhu cầu công việc (Deep Learning, Làm phim 4K ProRes, Gaming 4K, Edge AI), hệ thống tự động đề xuất cấu hình iPhone + NVIDIA tối ưu kèm bảng tính tiết kiệm khi mua combo.
* **Chi tiết kỹ thuật chuyên sâu (Tech Specs Matrix):** Hiển thị chi tiết bảng thông số chuẩn (CUDA cores, Tensor Cores, TDP, A18 Pro benchmarks, Megapixels, Zoom quang học).
* **Giỏ hàng thời gian thực & Áp mã Voucher:** Cập nhật số lượng, tạm tính, mã ưu đãi (`TITANVIP`, `SYNERGY`), kiểm tra tồn kho tức thì.
* **Quy trình Thanh toán & Đặt hàng hoàn chỉnh:** Form thông tin giao hàng chuẩn, lựa chọn phương thức thanh toán (COD, Chuyển khoản QR Techcombank 24/7, Trả góp 0%), xuất mã vận đơn tra cứu tức thì.
* **Tra cứu tình trạng đơn hàng:** Kiểm tra trạng thái đơn hàng theo mã (vd: `ORD-2026-8899`) mọi lúc.

### 4.2. Hệ Thống Backend & Quản Trị API (Backend Core)
* **FastAPI Modular Monolith:** Kiến trúc phân tầng rõ rệt: `core/`, `models/`, `schemas/`, `routers/`.
* **Cơ chế phản hồi chuẩn Envelope:** Mọi endpoint trả về định dạng nhất quán `{ success, data, meta, error }`.
* **Cơ sở dữ liệu SQLAlchemy 2.0:** Quan hệ đầy đủ giữa Brands, Categories, Products, Specifications, Bundles, Orders, OrderItems.
* **Khởi tạo dữ liệu tự động (Seed Catalog):** Script nạp sẵn đầy đủ 18+ sản phẩm thực tế với thông số kỹ thuật chuẩn xác, hình ảnh sắc nét và giá niêm yết VND thực tế.

## 5. Kiến Trúc Kỹ Thuật (Technical Architecture)

```
[ Next.js 14 Web App (App Router + Tailwind CSS + Lucide) ]
                             │  HTTP / REST (JSON Envelope)
                             ▼
[ FastAPI Backend (Port 8000) - Python 3.11/3.14 ]
     ├── Routers: /products, /categories, /bundles, /orders, /advisor
     ├── Middlewares: CORS, Timing, Exception-to-Envelope Handler
     └── Core: Config, Security, Database Engine
                             │  SQLAlchemy ORM
                             ▼
[ Relational Database (PostgreSQL 16 / SQLite Engine Fallback) ]
```

## 6. Tiêu Chuẩn Triển Khai (Deployment Targets)

1. **Docker Compose:** Chạy toàn bộ hệ thống bằng 1 lệnh duy nhất (`make up` hoặc `./start.sh`).
2. **Môi trường Cloud / VPS Production:** Đầy đủ tài liệu cấu hình Reverse Proxy Nginx, chứng chỉ SSL Let's Encrypt, biến môi trường bảo mật, CI/CD GitHub Actions.
3. **Serverless / Managed Hosting:** Hướng dẫn triển khai Frontend trên Vercel và Backend trên Railway / Render / Fly.io.
